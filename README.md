# sysprog-start

Мои работы по дисциплине «Системное программирование»: лабораторные работы, агент-сторож компьютера
(ядро на C, мозг на Python), домашние задания, тесты и курсовая работа.

| | |
|---|---|
| Автор | Ульзутуев Тимофей |
| Группа | 9/3-РПО-24/1 |
| Курс | 2026/2027 |
| Система | macOS |
| Языки | C, Python 3 |
| Редактор | VS Code |

## Лучшие работы

| Работа | Что сделано |
|---|---|
| [`agent`](agent/core/README.md) | агент-сторож v1: ядро на C (`core_get_info`, время работы системы), мозг на Python через ctypes, сообщение уходит в n8n, модель в Ollama объясняет его письмом |
| [`labs/02-debugger`](labs/02-debugger/README.md) | программа на C по шагам в отладчике LLDB: переменные, массив по байтам, стек вызовов, машинный код |
| [`labs/03-libraries`](labs/03-libraries/README.md) | библиотеки файла и процесса, загрузка libpcap в Python через ctypes |
| [`labs/01-process-inside`](labs/01-process-inside/README.md) | своя программа в Мониторинге системы: PID, память, дескрипторы, библиотеки, сигнал SIGTERM |

## Структура

```
sysprog-start/
├── labs/          лабораторные работы: одна папка на пару
├── agent/         агент-сторож: core — ядро на C, brain — мозг на Python
├── homework/      домашние задания
├── exams/         тесты и курсовая работа
├── checks/        автоматические проверки (ведёт преподаватель)
├── lectures/      конспекты глав (ведёт преподаватель)
├── materials/     файлы с занятий (ведёт преподаватель)
└── docs/          правила сдачи и обновления (ведёт преподаватель)
```

## Проверки

После каждой отправки кода GitHub Actions собирает работы на трёх серверах — Windows, macOS и Linux —
и запускает [проверки](checks/README.md). Результат: вкладка **Actions** → **Проверки** → **Summary**.

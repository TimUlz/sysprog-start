# ЛР 1. Процесс изнутри

Своя программа на C и на Python запущена и рассмотрена в Мониторинге системы macOS: номер процесса, память, открытые файлы, загруженные библиотеки и разница между завершением из монитора и обычным выходом.

| Файл | Что в нём |
|---|---|
| [`hello.c`](hello.c) | программа на C: печатает свой PID через `getpid()` и ждёт Enter |
| [`hello.py`](hello.py) | та же программа на Python: вызывает `getpid()` из libc через `ctypes` |
| [`report.md`](report.md) | отчёт с числами с экрана |

## Результаты

| | Программа на C | Программа на Python |
|---|---|---|
| Имя процесса в мониторе | hello | Python |
| PID (вывод программы = монитор) | 45455 | 45532 |
| Физическая память | 1,6 МБ | 11,8 МБ |
| Потоков | 1 | 1 |
| Дескрипторы | 3 — `/dev/ttys000` | — |
| Библиотеки | 80 `.dylib`, в том числе `libSystem.B.dylib` | те же и `Python3`, модуль `_ctypes` |
| Завершение из монитора | `zsh: terminated ./hello`, код 143 | — |
| Обычный выход | — | код 0 |

Код 143 = 128 + 15: процесс остановлен сигналом SIGTERM и не дошёл до `return 0`.

Сборка и запуск: `clang -o hello hello.c && ./hello`, `python3 hello.py`.

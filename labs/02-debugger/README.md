# ЛР 2. Программа в отладчике

Программа на C пройдена по шагам в отладчике VS Code (LLDB): точка останова, шаг с обходом и с заходом в функцию, переменные до и после присваивания, массив по байтам, стек вызовов и машинный код строки.

| Файл | Что в нём |
|---|---|
| [`debug.c`](debug.c) | структура `point`, массив `name`, цикл и функция `area` |
| [`.vscode/launch.json`](.vscode/launch.json) | запуск под LLDB, `targetArchitecture: arm64` для Apple Silicon |
| [`.vscode/tasks.json`](.vscode/tasks.json) | сборка `clang -g -O0 -Wall -Wextra` перед отладкой |
| [`report.md`](report.md) | отчёт с значениями из отладчика |

## Результаты

| Что смотрели | Значение |
|---|---|
| Вывод программы | `agent: total=6 area=12` |
| `p.x`, `p.y`, `total` до строки 15 | -94881664, 1, 1 — мусор из памяти |
| `p` после строки 15 | `{3, 4}` |
| `name` после `strcpy` | 97 'a', 103 'g', 101 'e', 110 'n', 116 't', ноль в `[5]` |
| Цикл, второй проход | `i = 2`, `total = 1` → после шага 3 |
| Стек внутри `area` | `debug!area` (стр. 10) → `debug!main` (стр. 22) → `start` |
| Умножение в машинном коде | `mul w8, w8, w9` |
| Перед `printf` | `a = 12`, `total = 6` |
| Код завершения | 0 |

Сборка без отладчика: `clang -g -O0 -Wall -Wextra -o debug debug.c && ./debug`.

# ЛР 3. Библиотеки программы

Какие библиотеки записаны в файле программы и какие загружены в работающий процесс; загрузка новой библиотеки в процесс Python через `ctypes` и вызов её функции.

| Файл | Что в нём |
|---|---|
| [`libs.c`](libs.c) | программа считает `sqrt` от числа из `argc` |
| [`report.md`](report.md) | отчёт с результатами |

## Результаты

| Что смотрели | Результат |
|---|---|
| Вывод программы | `./libs: sqrt(2) = 1.414214` |
| `otool -L libs` | одна библиотека — `/usr/lib/libSystem.B.dylib` (C, математика и системные вызовы в ней вместе) |
| `otool -L` для `python3` | `@executable_path/../Python3` и `libSystem.B.dylib`: интерпретатор лежит в библиотеке |
| Библиотек в процессе Python | 203 до `ctypes.CDLL`, 205 после |
| Новые библиотеки | `/usr/lib/libpcap.A.dylib` и `/usr/lib/libffi.dylib` |
| `pcap_lib_version()` | `b'libpcap version 1.10.1'` |

Сборка: `clang -o libs libs.c && ./libs`.

# ЛР 4. Дерево процессов

Дерево процессов в «Мониторинге системы» (вид «Все процессы, иерархически»): с какого процесса начинается система, кто родители терминала и браузера, проверка родителя командой `ps` и судьба процесса, у которого завершился родитель.

## Результаты

| Что смотрели | Результат |
|---|---|
| Начало дерева | `kernel_task` 0 → `launchd` 1, все остальные процессы — потомки `launchd` |
| Цепочка терминала | `zsh` 88525 → `zsh` 88508 → `login` 88507 → `Терминал` 57601 → `launchd` 1 |
| Дочерний процесс | `sleep 600 &` получил номер 88529, родитель 88525 — оболочка (`echo $$`) |
| Проверка командой | `ps -o pid,ppid,comm -p $!` → `88529 88525 sleep` |
| Браузер | `Google Chrome` 59223 и 26 дочерних процессов, вкладки — `Google Chrome Helper (Aperitif Renderer)` |
| Сирота | `sleep 900` 88748: родитель до — `bash` 88747, после его завершения — `launchd` 1 |
| Сирота в мониторе | стоит прямо под `Терминал`, а не под оболочкой: монитор группирует по ответственному приложению |

Кода в работе нет, все команды выполнены в терминале.

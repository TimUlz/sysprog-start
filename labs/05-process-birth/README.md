# ЛР 5. Рождение процесса

Запись обращений к ядру программой `fs_usage` (macOS): как оболочка создаёт процесс, какие файлы он открывает при загрузке, как код завершения доходит до родителя, что происходит при запуске несуществующей программы и как программу запускает Python.

## Результаты

| Что смотрели | Результат |
|---|---|
| Рождение | `bash` 89622 → `hostname` 91240; в записи `execve /bin/hostname` от процесса `bash` (fork, затем execve) |
| Библиотеки | в файле одна — `/usr/lib/libSystem.B.dylib`, при запуске подгружается из `dyld_shared_cache_arm64e` |
| Код завершения | `bash -c 'exit 7'` → у родителя `$?` = 7 |
| `env nosuch` | 20 попыток `execve` — по одной на папку `PATH`, ошибка ENOENT, код 127 |
| Запуск из Python | Python 91275 → `hostname` 91276; `subprocess` перебирает папки `PATH` через `execve` (13 неудачных попыток), оболочка сразу запускает полный путь |

Кода в работе нет, все команды выполнены в терминале.
